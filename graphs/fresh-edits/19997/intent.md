Let hosts attach a fee to custom booking questions (add-ons). In the booking form builder (packages/features/form-builder, FormBuilder and its schema), a field, or each option of a field, can have a price. Pricing is only offered for Number, Select, MultiSelect, Checkbox, Checkbox group and Radio group fields. The field dialog shows a price input (one per option for option-based fields) only when the host has turned the price field on, labelled with the event's payment currency. The event type editor UI, which renders the FormBuilder for booking questions, turns the price inputs on for paid event types and passes the event type's payment currency.

When a booking is paid for, handlePayment (packages/features/bookings/lib/handlePayment.ts, the payment collection service) adds the fees of the booker's paid answers (priced fields and selected priced options) to the event type's base price before creating or holding the payment. With no booking fields or no priced answers the amount is unchanged. handleNewBooking now also passes the event type's booking fields and the booker's locale to handlePayment so these fees can be worked out.
