# Prose briefs

One short request per task, for the `prose-brief` condition: what a busy developer would actually type to a coding
assistant. The agent gets it on top of the PR description and interface spec, in place of the long prose intent
(`../prose-intents/`), so the conditions run from no extra words (`prose`) to a brief, to the full intent.

Rules: 1-3 sentences (20-37 words here), plain and casual; the goal plus at most one key point. No file paths,
function/type/variable names, test names, code, lists or headings, nothing from the spec, and nothing that is not in
the matching intent.

Drafted by Claude from the intents on 2026-11-27, then cut down by hand to the goal and one point. Not yet reviewed
by a person.
